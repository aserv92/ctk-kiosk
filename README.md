# Surface Pro 3 Alpine Kiosk

A custom Alpine Linux image for Microsoft Surface Pro 3 tablets used as data-collection kiosks in manufacturing environments.

The image boots directly into a graphical session and launches Chromium in kiosk mode, displaying a configured web application. It is intended for dedicated operator interfaces on the shop floor where the tablet serves a single purpose.

## Overview

- Based on Alpine Linux
- Designed for Surface Pro 3 hardware
- Starts a graphical environment on boot
- Runs Chromium full-screen in kiosk mode
- Suitable for unattended data collection stations

## Intended Use

Operator kiosks, work-order terminals, quality data collection points, and similar single-purpose interfaces in machine shops and manufacturing facilities.
